# SEMA NEXUS — Banco de dados (Oracle)

> **Status:** Planejado. As tabelas serão criadas pelas migrations Flyway das Issues #3 (Core), #11 (Flux), #15 (DocIA) e #25 (Notificações, P1).
> **Oracle é obrigatório.** Não usar PostgreSQL, MySQL, H2 ou SQLite em nenhum ambiente, nem em testes.

## Ambiente

| Item | Valor |
|---|---|
| Versão | Oracle Database 23ai Free |
| Imagem | `gvenzl/oracle-free:23-slim-faststart` (tag/digest fixado na Issue #8) |
| Serviço / PDB | `FREEPDB1` |
| URL JDBC (Docker) | `jdbc:oracle:thin:@//oracle:1521/FREEPDB1` |
| URL JDBC (host) | `jdbc:oracle:thin:@//localhost:1521/FREEPDB1` |
| Usuário da aplicação | `APP_USER` (criado pela imagem a partir do `.env`) |
| Versionamento | Flyway, `src/main/resources/db/migration/V<n>__<descricao>.sql` |
| Requisitos | ~2 GB de RAM para o container (host com 8 GB+), ~4 GB de disco, 1ª subida em 1–3 min |

## Convenções

- Tabelas e colunas em MAIÚSCULAS, singular. PK `ID NUMBER GENERATED BY DEFAULT AS IDENTITY`.
- `CRIADO_EM` / `ATUALIZADO_EM` (`TIMESTAMP`); exclusão lógica com `EXCLUIDO_EM` quando aplicável.
- Enums como `VARCHAR2` + `CHECK`. FKs nomeadas `FK_<TABELA>_<REF>`; índices `IX_<TABELA>_<COLUNA>`.
- `spring.jpa.hibernate.ddl-auto=validate`: o Hibernate **não** cria schema; só o Flyway.
- Migration aplicada na `main` nunca é editada; crie uma nova.

## Catálogos (enums)

- **Origem:** Denúncia, Monitoramento, Solicitação institucional, Ação planejada, Análise ambiental.
- **Categoria ambiental (somente fiscalização):** Desmatamento ilegal, Queimada/incêndio, Recursos hídricos, Fauna silvestre, Pesca irregular, Mineração irregular, Resíduos e poluição, Área de preservação permanente.
- **Prioridade:** Baixa, Média, Alta, Urgente.
- **Status:** PENDENTE, EM_TRIAGEM, AGUARDANDO_DISTRIBUICAO, DISTRIBUIDA, EM_ANDAMENTO, AGUARDANDO_CONCLUSAO, FINALIZADA.
